# CRUD de Filmes

Sistema de cadastro de filmes no terminal, feito com Python e SQLite.

## Funcionalidades

- Cadastrar filme (título, ano, gênero e nota)
- Listar filmes
- Atualizar a nota de um filme
- Apagar um filme

## Tecnologias

- Python
- SQLite (módulo sqlite3)

## Como rodar

    python main.py
